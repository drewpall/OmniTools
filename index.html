      • 本工具基于 WebRTC 技术，文件数据直接在两台设备之间点对点传输，绝不经过任何服务器。This tool uses WebRTC. Files transfer directly end-to-end and never pass through any server.
      • 如果两台设备在同一 WiFi 下，传输速度可达局域网最大带宽，完全不耗费公网流量。If both devices are on the same WiFi, speed can reach max LAN bandwidth without using internet traffic.
      • 如果跨网传输（如一台连 WiFi，一台用 5G），速度取决于发送端的网络上传速度。For cross-network transfers (e.g. WiFi to Cellular), speed depends on the sender's upload rate.
